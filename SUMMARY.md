## 🚀 Как начать использовать

### Вариант 1: Быстрый старт (5 минут)

```bash
# 1. Установить зависимости
npm install

# 2. Запустить dev сервер
npm run dev

# 3. Открыть http://localhost:5173
```

**Готово!** Приложение запущено на вашем компьютере.

### Вариант 2: С Just (если установлен)

```bash
just setup    # install + dev в одной команде
```

### Вариант 3: Для production

```bash
npm run build       # Собрать
npm run preview     # Просмотреть
```

Подробнее: см. [docs/QUICKSTART.md](docs/QUICKSTART.md)
