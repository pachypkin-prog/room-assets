# Room&Assets Manager - Спецификация

## 📋 Описание проекта

**Room&Assets** — приложение для управления ресурсами (аудитории и оборудование) и системой броней на эти ресурсы.

Основная задача: помочь организациям эффективно управлять доступностью аудиторий и инвентаря, предотвращая конфликты расписания.

## 👥 Пользовательские истории

### US-1: Просмотр каталога ресурсов
**Как** менеджер помещений  
**Я хочу** увидеть все доступные аудитории и оборудование  
**Чтобы** знать какие ресурсы есть в наличии  

**Критерии приёма:**
- [ ] Отображаются все аудитории с названием и вместимостью
- [ ] Отображаются все единицы оборудования с инвентарным номером и статусом
- [ ] Можно искать по названию (поиск в реальном времени)
- [ ] Интерфейс адаптивный для мобильных устройств

### US-2: Создание новой брони
**Как** организатор мероприятий  
**Я хочу** создать новую бронь на аудиторию или оборудование  
**Чтобы** зарезервировать ресурс на нужное время  

**Критерии приёма:**
- [ ] Форма позволяет выбрать ресурс (аудиторию или оборудование)
- [ ] Форма позволяет указать дату и время начала/окончания
- [ ] Форма позволяет добавить название и примечание
- [ ] При сохранении проверяется что время не пересекается с другими бронями на тот же ресурс
- [ ] При ошибке валидации показывается понятное сообщение
- [ ] После успешного создания бронь видна в списке

### US-3: Просмотр списка броней
**Как** менеджер  
**Я хочу** видеть все существующие брони  
**Чтобы** контролировать расписание и избежать конфликтов  

**Критерии приёма:**
- [ ] Брони отображаются в таблице, отсортированные по времени
- [ ] Для каждой брони видно: название, ресурс, время, примечание
- [ ] Можно искать по названию события
- [ ] Время отображается в локальном часовом поясе пользователя

### US-4: Редактирование брони
**Как** менеджер  
**Я хочу** изменить существующую бронь  
**Чтобы** корректировать расписание при изменении плана  

**Критерии приёма:**
- [ ] Кнопка "Редактировать" открывает форму с предзаполненными данными
- [ ] При изменении применяются те же правила валидации
- [ ] Изменения сохраняются в базу

### US-5: Удаление брони
**Как** менеджер  
**Я хочу** удалить бронь  
**Чтобы** освободить ресурс  

**Критерии приёма:**
- [ ] Кнопка "Удалить" рядом с каждой бронью
- [ ] Перед удалением показывается подтверждение
- [ ] После удаления бронь исчезает из списка

### US-6: Экспорт данных
**Как** администратор  
**Я хочу** скачать все данные в JSON  
**Чтобы** сделать резервную копию или передать коллеге  

**Критерии приёма:**
- [ ] Кнопка экспорта в шапке приложения
- [ ] Скачивается JSON файл со всеми аудиториями, оборудованием и бронями
- [ ] Имя файла содержит дату: `room-assets-YYYY-MM-DD.json`

### US-7: Импорт данных
**Как** администратор  
**Я хочу** загрузить данные из JSON файла  
**Чтобы** восстановить или синхронизировать данные  

**Критерии приёма:**
- [ ] Кнопка импорта в шапке приложения
- [ ] Диалог выбора файла
- [ ] При импорте все текущие данные заменяются на данные из файла
- [ ] Показывается подтверждение при успехе или сообщение об ошибке

## 🎯 MVP (Minimum Viable Product)

### Версия 1.0

**Функциональность:**
1. ✅ Просмотр каталога аудиторий и оборудования
2. ✅ Создание, редактирование, удаление броней
3. ✅ Просмотр списка броней с сортировкой и поиском
4. ✅ Валидация пересечений времени
5. ✅ Импорт/экспорт данных в JSON
6. ✅ Локальное хранилище IndexedDB
7. ✅ Поддержка локальных часовых поясов

**Ограничения:**
- Нет аутентификации (приложение для одного пользователя)
- Нет синхронизации между устройствами
- Нет истории изменений

### Возможные расширения (v2.0+)

- Фильтры по дате, ресурсу, статусу
- Управление ресурсами (добавление/удаление аудиторий и оборудования)
- Экспорт в CSV, PDF
- Уведомления о приближающихся бронях
- Тёмная тема
- Синхронизация с календарём (Google Calendar, Outlook)
- Backend интеграция с WebSocket для совместной работы

## ✅ Бизнес-правила

### Валидация данных

1. **Брони не могут пересекаться** для одного ресурса
   - Пример: Если `Room-101` забронирована с 09:00 до 10:00, нельзя создать бронь с 09:30 до 10:30

2. **Время начала < время окончания**
   - Невозможно создать бронь где окончание раньше начала

3. **Ресурс должен существовать**
   - Нельзя забронировать несуществующую аудиторию или оборудование

4. **Необходимые поля**
   - Название, тип ресурса, ресурс, дата/время начала и окончания обязательны

### Работа со временем

- **Формат хранения**: ISO 8601 в UTC (например: `2025-09-05T08:00:00Z`)
- **Отображение**: Локальный часовой пояс пользователя (автоматическое преобразование)
- **Поддерживаемые браузеры**: Все современные браузеры (Chrome, Firefox, Safari, Edge)

## 🔍 Поиск и фильтры

- **Поиск по названию**: ищет в названиях событий, аудиторий, оборудования
- **Поиск по примечанию**: ищет текст в примечаниях к броням
- **Фильтр по дате**: показывает только брони на выбранную дату (опционально)
- **Фильтр по ресурсу**: показывает только брони конкретного ресурса (опционально)

## 🚫 Ограничения и известные проблемы

- Приложение работает для одного пользователя (нет многопользовательской синхронизации)
- Очищение данных браузера удалит все брони
- Максимальный объём данных в IndexedDB ~ 50MB (достаточно для тысяч броней)
- Нет истории изменений или отката операций

## 📱 Требования к браузерам

- Chrome 60+
- Firefox 55+
- Safari 11+
- Edge 79+

Работает как на Windows, так и на Linux (кроссплатформенность).
