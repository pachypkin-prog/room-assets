## 🎯 Использование документации в разных ситуациях

### Ситуация 1: "Я только начинаю"
```
1. Прочитайте QUICKSTART.md (5 мин)
2. Запустите приложение (2 мин)
3. Создайте первое бронирование (3 мин)
4. Прочитайте FAQ.md если возникнут вопросы
```

### Ситуация 2: "Я хочу добавить функцию"
```
1. Прочитайте CONTRIBUTING.md → Добавление нового (10 мин)
2. Прочитайте DECISIONS.md → Ваш тип изменения (15 мин)
3. Посмотрите пример в CONTRIBUTING.md
4. Кодите!
5. Прочитайте TESTING.md → Как тестировать
```

### Ситуация 3: "Я вижу ошибку"
```
1. Прочитайте QUICKSTART.md → Troubleshooting (5 мин)
2. Прочитайте FAQ.md → Troubleshooting (5 мин)
3. Откройте GitHub Issue с подробным описанием
4. Приложите скриншот и шаги воспроизведения
```

### Ситуация 4: "Я хочу развернуть в production"
```
1. Прочитайте DEPLOYMENT.md → Локальное тестирование (10 мин)
2. Выберите платформу (GitHub Pages, Vercel, Netlify)
3. Следуйте инструкциям для вашей платформы (10-20 мин)
4. Проверьте работоспособность
5. Настройте мониторинг (опционально)
```

### Ситуация 5: "Я хочу понять архитектуру"
```
1. Прочитайте ARCHITECTURE.md → Общая структура (15 мин)
2. Посмотрите диаграммы компонентов
3. Следуйте потокам данных
4. Прочитайте DECISIONS.md → Почему эта архитектура (10 мин)
5. Посмотрите код в src/App.tsx
```
